# Yards-ee Caddie

Odds and strategy helper for the Yards-ee Golf dice game: what to hold, when to use a mulligan, and when to take a RollBuster bonus. It calculates exact odds for every possible hold.

**Use it:** open the GitHub Pages link on your phone, then use Share → Add to Home Screen (iPhone) or the Install / Add to Home screen menu (Android). After the first visit it works offline.

Everything runs in your browser. Your settings and round stats stay on your device.
